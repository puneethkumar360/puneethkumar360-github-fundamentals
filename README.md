# GitHub Fundamentals I

This repository contains a small C program that prints a greeting. I created it for GitHub Fundamentals I to practice tracking changes with Git and publishing a repository on GitHub. The commit history records the introduction, the program, and instructions for building and running it on macOS.

## Collaboration Log

- **Partner:** Ranjan ([@ranjann7](https://github.com/ranjann7)).
- **What we built:** In VS Code Live Share, Ranjan moved the greeting into `static void greet(void)` in `hello.c` and updated `main()` to call it. The program compiled on macOS and still printed `Hello, GitHub!`.
- **Takeaway:** Running the program before and after extracting a function is a simple way to check that a refactor preserves its visible behavior.
